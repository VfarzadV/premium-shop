## 📖 درباره پروژه

**فروشگاه پریمیوم** یک اپلیکیشن تجارت الکترونیک مدرن و در سطح سازمانی (Enterprise) است که با استفاده از **(App Router) Next.js** توسعه یافته است. این پلتفرم با ترکیب **نمایشگر سه‌بعدی محصولات**، **سیستم هوشمند کلوپ مشتریان** و یک **داشبورد مدیریت جامع**، فراتر از یک فروشگاه آنلاین معمولی عمل می‌کند. طراحی این سایت با رویکرد Mobile-First انجام شده و تجربه‌ای روان، مشابه اپلیکیشن‌های بومی (Native) را در تمامی دستگاه‌ها با پشتیبانی از حالت تاریک/روشن تضمین می‌کند.

## ✨ ویژگی‌های کلیدی

- **🧊 ویترین تعاملی سه‌بعدی:** رندر مدل‌های سه‌بعدی با کیفیت بالا مستقیماً در مرورگر با استفاده از `React Three Fiber`، با قابلیت چرخش و بررسی دقیق زوایای محصول.
- **💳 فرآیند پرداخت پیشرفته (Checkout):** پرداخت چندمرحله‌ای شامل نقشه تعاملی **Leaflet** برای انتخاب دقیق آدرس و محاسبه پویای هزینه ارسال.
- **🎁 کلوپ مشتریان هوشمند:** سیستم وفاداری خودکار که به کاربران پس از هر خرید امتیاز می‌دهد. این امتیازها به کدهای تخفیف داینامیک و امن (مانند `PRM-XXXX`) تبدیل می‌شوند.
- **🛡️ داشبورد مدیریت یکپارچه:** یک پنل ادمین محافظت‌شده با نمودارهای تحلیلی داینامیک `Recharts` برای رصد فروش، مدیریت سفارشات و بررسی موجودی محصولات.
- **🔍 جستجوی زنده و فیلترینگ پیشرفته:** جستجوی لحظه‌ای با سیستم ضدتداخل (Debouncing) به همراه فیلترهای چندگانه (دسته‌بندی، برند، قیمت و امتیاز).
- **⚖️ مقایسه هوشمند و علاقه‌مندی‌ها:** امکان مقایسه دقیق و هوشمندانه مشخصات چندین محصول در کنار هم و ذخیره کالاهای محبوب در لیست علاقه‌مندی‌ها.
- **🌓 تم تطبیق‌پذیر:** تغییر یکپارچه بین حالت تاریک (Dark Mode) و روشن با قابلیت تشخیص خودکار تم سیستم عامل کاربر.

## 🧠 معماری و ساختار داخلی (Under The Hood)

این پروژه با بهره‌گیری از الگوهای پیشرفته‌ی React و Next.js مهندسی شده تا بالاترین سطح مقیاس‌پذیری، امنیت و پرفورمنس را ارائه دهد:

*   **مدیریت استیت قدرتمند:** استفاده از `Zustand` برای مدیریت استیت‌های سراسری (سبد خرید، اطلاعات کاربر، سفارشات و امتیازات) مجهز به میدلور `persist` برای همگام‌سازی با `localStorage`.
*   **جلوگیری از خطای Hydration:** پیاده‌سازی همگام‌سازی سفارشی با `useEffect` برای جلوگیری از تداخلات SSR/CSR در Next.js هنگام خواندن داده‌های لوکال استوریج.
*   **مهار Race Condition:** ورودی جستجوی زنده از یک مکانیزم پیچیده با استفاده از فلگ‌های بولین (Boolean Flags) در کنار `Debounce` ۵۰۰ میلی‌ثانیه‌ای استفاده می‌کند تا از تداخل پاسخ‌های API در هنگام تایپ سریع کاربر جلوگیری کند.
*   **منطق تجاری (Business Logic) سخت‌گیرانه:** اعمال محدودیت‌های هاردکد شده برای جلوگیری از اضافه شدن کالاهای ناموجود به سبد خرید (بای‌پس کردن UI)، به همراه اعتبارسنجی دقیق کدهای تخفیف قبل از اعمال در فاکتور نهایی.
*   **تفکیک کامپوننت‌های Server و Client:** رعایت دقیق معماری Next.js 14 با جداسازی کامپوننت‌های سمت سرور بهینه‌شده برای سئو (`layout.tsx`, `page.tsx`) از کامپوننت‌های تعاملی سمت کلاینت (`ProductClient.tsx`).

## 💻 تکنولوژی‌های استفاده شده (Tech Stack)

- **فریم‌ورک اصلی:** Next.js 14 (App Router)
- **کتابخانه پایه:** React 18, TypeScript
- **استایل‌دهی:** Tailwind CSS, next-themes
- **مدیریت استیت:** Zustand
- **رندر 3D:** Three.js, @react-three/fiber, @react-three/drei
- **آیکون و رابط کاربری:** Lucide React, SweetAlert2, Swiper
- **نقشه و نمودار:** React-Leaflet, Recharts
- **منبع داده (API):** DummyJSON REST API

## 📂 ساختار پوشه‌ها (Folder Structure)

```text
src/
├── app/              # مسیرها و صفحات اصلی پروژه در Next.js
│   ├── admin/        # مسیرهای محافظت‌شده داشبورد مدیریت
│   ├── cart/         # صفحه سبد خرید
│   ├── checkout/     # مراحل چندگانه پرداخت و ثبت سفارش
│   ├── compare/      # منطق و رابط کاربری مقایسه محصولات
│   └── product/      # صفحات داینامیک جزئیات محصول و نمایش 3D
├── components/       # کامپوننت‌های قابل استفاده مجدد (منوها، کارت‌ها، مودال‌ها)
├── store/            # بخش‌های مدیریت استیت Zustand
├── public/           # فایل‌های استاتیک (فونت‌ها، تصاویر، مدل‌های سه‌بعدی)
└── utils/            # توابع کمکی و متغیرهای ثابت (مانند نرخ تبدیل ارز)

🚀 راه‌اندازی پروژه

برای نصب و اجرای این پروژه روی سیستم لوکال خود، مراحل زیر را دنبال کنید:
پیش‌نیازها

    نصب بودن Node.js (نسخه 18 به بالا توصیه می‌شود)

    npm یا yarn

نصب و اجرا

۱. کلون کردن ریپازیتوری
Bash

git clone [https://github.com/VfarzadV/premium-shop.git](https://github.com/VfarzadV/premium-shop.git)

۲. نصب پکیج‌ها و وابستگی‌ها
Bash

cd premium-shop
npm install

۳. اجرای سرور توسعه (Development Server)
Bash

npm run dev

مرورگر خود را باز کرده و آدرس http://localhost:3000 را وارد کنید.

    💡 دسترسی به پنل مدیریت: برای تست و بررسی داشبورد ادمین، به صفحه ورود (Login) رفته و از شماره موبایل 09999999999 استفاده کنید.
